Проект 2. Поиск вакансий

 - создан абстрактный класс GetVacAPI для работы с API сервиса с вакансиями. Реализован класс HeadHunterHAPI, наследующийся от абстрактного класса, для работы с платформой hh.ru. Класс умеет подключаться к API и получать вакансии;
 - создан класс HHVacancy для работы с вакансиями. В этом классе определены атрибуты, такие как идентификатор вакансии, название, расположение, нижняя граница зарплаты, верхняя граница зарплаты. Класс поддерживает методы сравнения вакансий между собой по зарплате и валидирует данные, которыми инициализируются его атрибуты;
 - определен абстрактный класс BaseVacancyFile, который обязывает реализовать методы для добавления вакансий в файл, получения данных из файла по указанным критериям и удаления информации о вакансиях. Создан класс VacancyFile, реализующий методы базового класса BaseVacancyFile. Созданы классы SafeVacancyJson, SafeVacancyExcel, SafeVacancyTxt для сохранения информации о вакансиях в JSON-файл и сохранения в другие форматы - Excel-файл, TXT-файл;
 - создана функция user_interact для взаимодействия с пользователем. Функция взаимодействует с пользователем через консоль. Возможности этой функции следующие: ввести поисковый запрос для запроса вакансий из hh.ru, получить топ N вакансий по зарплате (N запрашивать у пользователя), получить вакансии с ключевым словом в описании.

 - в модуле main приведена последовательность вызовов и команд, отражающих работу всех классов и функций. В модуле user_interact.py размещена функция взаимодействия с пользователем и её вызов. При запуске модуля main есть возможность выбора - проверить работу с классами или запустить функцию взаимодействия с пользователем.

 - составлены тесты.
